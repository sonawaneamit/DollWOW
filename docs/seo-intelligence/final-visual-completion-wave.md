## Release Rules

- Do not generate a batch for a new visual family before its first sample is approved.
- Use only live, correctly classified, adult-looking, supplier-authorized products.
- Verify every embedded number and label against current product data or the dated dataset.
- Preserve source identities; do not manufacture a new doll or imply a generated person is the SKU.
- Use clean source images when available and record watermark status.
- Provide a vertical mobile-first master and a suitable desktop treatment.
- Insert descriptive alt text, a visible caption, and a relevant product, brand, collection, or guide link.
- Run mobile and desktop crop QA before release.
