# Customization family profiles

## Purpose

Customization must be managed at the narrowest verified reusable family, not copied manually to every product. A product-specific imported configuration always wins over a family profile when the product is known to differ.

## Resolution order

1. Product-specific restrictions and stock status.
2. Product-specific imported option groups and compatibility exceptions.
3. Brand/material/head-construction family profile.
4. No checkout option is shown when no source-backed profile applies.

This prevents a new listing from silently getting an unverified option set simply because it shares a brand name.

## WM Dolls rollout

Dealer configurators are the retail-option source of truth for the profiles below. Manufacturer sites can help classify a product broadly, but they are not used to reduce an option set when their configurator is incomplete.

| WM family | Shared configuration | Current treatment |
| --- | --- | --- |
| Female standard TPE custom build | 161 compatible TPE heads; one included head switch; one included extra head; additional heads at $299 each | Automatically inherited by matching new products. |
| Female silicone-head TPE custom build | 164 compatible silicone-head options; one included head switch; one included extra head; additional heads at $650 each | Automatically inherited by matching new products. |
| Female full-silicone custom build | Source-specific head compatibility and pricing | Uses imported product configuration only until a verified shared profile is captured. |
| Male, hybrid, PVC/anime, torso, hips, head-only, ready-to-ship | Product-specific | Never inherits the broad TPE libraries. |

For every normalized single-select appearance group, the customer can keep **As shown in product photos**. Multiple add-on groups always include **No add-on**. Image-backed visual choices that have a source-backed $0 price are available to DollVue when the product itself is eligible.

## Expand safely to other brands

Before a new family is enabled, capture and review: material/build scope, eligible head list, switch-head rule, included-extra-head rule, paid-extra-head price, non-head options, option images, option price data, incompatibilities, and ready-to-ship restrictions. Add a regression fixture before switching a family profile on.
